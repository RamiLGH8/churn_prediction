# Experiment configurations

Each YAML file describes one reproducible model-comparison experiment. Its
input is the feature CSV generated by DVC, so experiments do not repeat
cleaning, feature engineering, encoding, or scaling.

- `experiment.primary_metric` selects the metric used to choose the winner.
- `experiment.number_of_features` provides default SelectKBest values.
- `experiment.thresholds` lists classification thresholds evaluated from the
  same out-of-fold probabilities; evaluating another threshold does not refit
  a model.
- `models` contains enabled model families, fixed constructor parameters, and
  parameter grids. Every combination in `param_grid` is evaluated.

Run a configuration from the repository root:

```bash
python3 src/experiment.py --config src/experiments/experiment_01.yaml
```

Authentication secrets must be environment variables, never YAML values:

```bash
export MLFLOW_TRACKING_USERNAME="RamiLGH8"
export MLFLOW_TRACKING_PASSWORD="<your-dagshub-token>"
```

Create another experiment by copying the YAML file and changing its run name,
feature counts, model grids, thresholds, or cross-validation settings.
